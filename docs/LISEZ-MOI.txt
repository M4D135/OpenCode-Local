OPENCODE LOCAL — GUIDE RAPIDE
Version 1.0.0 — Windows 10/11 Intel/AMD x64 — 16 Go de RAM

INSTALLATION SANS INTERNET

Télécharger Setup.exe, Setup-1.bin et Setup-2.bin depuis la même version
GitHub, puis les placer ensemble dans un même dossier. Double-cliquer sur
Setup.exe. Aucun téléchargement n'est demandé sur le PC cible.

Le programme s'installe pour votre utilisateur Windows. Prévoir environ
12 Go libres pendant le téléchargement et l'installation. Le modèle est
assemblé automatiquement et son empreinte SHA-256 est vérifiée.

PREMIÈRE SESSION

1. Ouvrir OpenCode Local depuis le menu Démarrer.
2. Choisir le dossier du projet sur lequel travailler.
3. Conserver le contexte 32K au premier essai, puis cliquer sur OpenCode.
4. Attendre le chargement du modèle. La console OpenCode s'ouvre.
5. Écrire par exemple : « Lis le README et explique-moi ce projet. »

Les modifications et commandes demandent confirmation. Le modèle 4B reste
limité : vérifiez ses propositions et conservez une sauvegarde du projet.
Les compilateurs, environnements de projet et Git ne sont pas inclus.
L'interface d'OpenCode reste celle de sa version officielle ; vos demandes
peuvent être rédigées en français.

PORTS BLOQUÉS

OpenCode communique avec le modèle sur 127.0.0.1, un port local compris
entre 18741 et 18780. Aucune écoute sur le réseau et aucune règle de
pare-feu ne sont ajoutées. La clé de l'API locale change à chaque session.

Si les accès Internet sont bloqués mais que 127.0.0.1 reste autorisé, ce
mode peut fonctionner. Si la liaison locale est elle-même interdite,
utilisez Discussion directe : le modèle fonctionne sans serveur HTTP.
Cette discussion ne possède pas les outils de modification d'OpenCode.
Dans cette version du moteur direct, du texte entre balises <think> peut
apparaître avant la réponse. Attendre la réponse finale ; cette particularité
ne concerne pas le mode OpenCode avec son serveur local.

Le programme respecte les restrictions du PC. Si l'exécution d'un programme
est bloquée par l'organisation, faire autoriser l'installation.

ARRÊT, MÉMOIRE ET DÉPANNAGE

Fermer la console termine la session. Le bouton Arrêter ferme le moteur et
les processus de la session ; sauvegarder au préalable le travail en cours.
Fermer le lanceur arrête aussi sa session.

Fermer les applications lourdes avant utilisation. Le contexte 16K réduit
la consommation de mémoire, mais les outils occupent déjà une partie
importante du contexte. Le réglage 8K convient surtout aux tâches courtes.
La discussion directe utilise 4K. Aucune performance précise n'est garantie
sur votre processeur.

En cas d'erreur, ouvrir Diagnostic et Journaux. L'absence d'Internet n'est
pas une erreur. Les mises à jour, plugins externes, serveurs de langage,
recherche web et fournisseurs cloud sont désactivés dans le profil livré.
Une commande que vous autorisez peut toutefois accéder au réseau : le pack
n'est pas un système d'isolation réseau.

L'installateur et le lanceur d'intégration ne sont pas signés avec un
certificat commercial. Le fichier SHA256SUMS.txt de la release permet de
vérifier les téléchargements. Ne désactivez pas les protections du PC.

DONNÉES

Installation par défaut :
%LOCALAPPDATA%\Programs\OpenCodeLocal

Conversations, configuration et journaux :
%LOCALAPPDATA%\OpenCodeLocal

La désinstallation Windows conserve vos projets et le profil. Pour effacer
l'historique, fermer le lanceur puis supprimer volontairement ce profil.
